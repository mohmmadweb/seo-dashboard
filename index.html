How to read this page, and how to run it.

Status vocabulary

Met
Already at or past the 90-day target.
On track
The rate achieved so far, projected forward, reaches the target before the window closes.
Behind
Moving, but the current rate will not reach the target in time.
At risk
Progress is far below where the elapsed time says it should be.
Blocked
No credential, so nothing was measured. Excluded from the score — never counted as zero.

What the projection means

It is a straight line from the baseline through today. SEO compounds, so for a strategy that is working this understates the finish — treat it as a floor, not a forecast. It is there to answer one question: if nothing changes, do we make it?

Running it

cd /home/mlops/mohammad/lenzit-seo

# free — crawl + Google collectors
./.venv/bin/python seo-os/run_daily.py

# adds live SERP positions and referring domains (costs money)
./.venv/bin/python seo-os/run_daily.py --serp --backlinks --serp-budget 0.05

# re-render the page from stored data, no collection
./.venv/bin/python seo-os/run_daily.py --dashboard-only
